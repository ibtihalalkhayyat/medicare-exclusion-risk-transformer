About the 140-input schema and the actual calculation

The original model processes five annual positions (lag4 through lag0), with 27 numeric fields and one provider-type category at each position. Offline Python inference loaded the unchanged frozen checkpoint, fitted preprocessing, and Platt calibration. The website displays those outputs from a cached JSON file.

All fictional provider-type strings are mapped to the frozen model's unknown-category embedding. Model outputs for invented rows are not scientifically validated event-risk estimates. The 2023 final-test outcomes remain sealed.

Scope: research ranking of future observed HHS-OIG administrative exclusion for human review, not a determination of fraud. The sealed 2023 test has a 2026 outcome window and is not included.
